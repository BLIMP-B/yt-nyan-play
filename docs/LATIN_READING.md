# 英字の読み分け

v0.5.5から、読み上げる文章に英字がある場合は、辞書・チャット教育を適用した後、URL以外の英字列を次のように変換します。Botの通常チャット、読み上げテスト、X投稿、VOICEVOXへの棒読みちゃん前処理の発話文で適用します。

| 入力 | 読み方 |
| --- | --- |
| A / a / Ａ / ａ | エー |
| B / b | ビー |
| n / ｎ | ん |
| N / Ｎ | エヌ |
| ka / KA / ｋａ | か |
| nyan / NYAN | にゃん |
| gakkou | がっこう |
| shinnyuu | しんにゅう |
| kan'i | かんい |

空白・数字・記号・日本語との境界で英字列を区切ります。1文字は英字名で読み、小文字の単独nだけ「ん」とします。2文字以上はヘボン式・訓令式の音節、拗音、促音、撥音、小書き文字をひらがなへ変換します。大小文字と英字の全角・半角は同じローマ字として扱います。ローマ字に変換できない子音は英字名で補います。例えば `QR` は「キューアール」です。英語の意味や発音の推定は行いません。

有効な `http://`・`https://`・`ftp://`・`www.` のURLを変換対象から外します。「URLを読む」が無効の通常経路では、URLを従来どおり `URL` の省略表記に置き換えます。Markdownリンクは表示文字を読みます。URLの横にある英字列は変換します。チャットのメディア再生命令は読み上げ前に解析するので、動画ID・クエリ・再生位置は変更しません。

辞書・教育で明示した読み方を優先し、その置換結果の英字は再変換しません。正規表現のキャプチャ置換、サーバー・利用者の適用範囲、無音、忘却を維持します。例として `教育(nyan=CAT)` 後は `nyan` の読みを `CAT` のまま合成エンジンへ渡し、忘却後は「にゃん」へ戻します。

棒読みちゃん前処理では、原文・タグ構文をそのまま元の処理へ渡し、生成された発話部分へ変換を追加します。Sound等のタグ引数は変更しません。取り込み元の単語・教育辞書にある固定の英字読みも保持します。元のネイティブ辞書・タグの完全互換は引き続き照合対象です。

通常経路は変換後の文章も `speech.maxChars` の範囲に収めます。ネイティブ経路は元の文字数設定と文分割を維持します。Windows／Linuxの実Electron試験では、IPC→キュー→合成APIに渡る文章が `A b n N ka NYAN override https://example.test/ABC` → `エー ビー ん エヌ か にゃん CAT URL` となることを、音声フレーム出力と併せて検証します。合成エンジンは試験用応答を使用し、実VOICEVOXの声による聴き取り比較とは区別します。
