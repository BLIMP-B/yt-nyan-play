# 通話メディアの音声調整

「設定」→「通話メディアのイコライザー／コンプレッサー」で調整し、保存します。対象は全サーバーのDiscordへ送る動画・音楽と時報BGMです。PC側の再生、読み上げ、時報の告知と3点音には適用しません。既存設定の初期値は両方OFFです。

EQは100 / 300 / 1,000 / 3,000 / 8,000 Hzの5帯域をそれぞれ−12〜＋12 dBで調整できます。入力ゲインは−24〜＋6 dBです。

| EQプリセット | 用途 | 入力ゲイン | 帯域ゲイン（低域→高域） |
| --- | --- | --- | --- |
| フラット | 元のバランス | 0 dB | 0, 0, 0, 0, 0 |
| 音楽 | 低音と高音を軽く持ち上げる | −3 dB | 2, −1, 0, 1, 2 |
| 声を聞きやすく | 低音の重なりを減らし声の輪郭を出す | −3 dB | −4, −2, 1, 3, −1 |
| 低音を抑える | 低音の膨らみを減らす | 0 dB | −6, −3, 0, 0, 0 |
| 高音をやわらかく | 刺さる高音を抑える | 0 dB | 0, 0, 0, −2, −5 |

コンプレッサーは大きな音を抑えます。小さい音を常に増幅する仕組みではありません。静かな素材の全体音量を上げたい場合は補正ゲインを調整してください。

| プリセット | しきい値 | 圧縮比 | ニー | アタック | リリース | 補正ゲイン |
| --- | --- | --- | --- | --- | --- | --- |
| 軽め | −18 dB | 2:1 | 6 dB | 15 ms | 180 ms | 2 dB |
| 音量差を抑える | −24 dB | 3:1 | 8 dB | 10 ms | 250 ms | 4 dB |
| ピークを抑える | −9 dB | 8:1 | 3 dB | 1 ms | 100 ms | 0 dB |

カスタムでは、しきい値−60〜0 dB、圧縮比1〜20、ニー0〜24 dB、アタック1〜100 ms、リリース20〜1,000 ms、補正ゲイン0〜12 dBを設定できます。プリセット選択で有効になり、数値を変更するとカスタムになります。有効チェックを外すとバイパスします。保存後、再生中のVCとBGMに反映し、設定バックアップと再起動でも保持します。

音声の順序は **EQ → ステレオ連動コンプレッサー → ピーク保護 → 動画音量・読み上げ減衰・フェード → 読み上げとの混合 → Opus送信** です。メディアとBGMは別のフィルター状態を持ち、停止時にリセットします。読み上げ時の減衰割合、時報の割り込み、3秒を初期値とするフェードは維持します。左右の音量差を保ち、無音は無音のまま送ります。

EQや圧縮は音のバランス・音量差を整えるもので、Discordの圧縮で失われた情報を復元するものではありません。音楽用途のOpus設定と、低音量でも送信を継続する設定は引き続き使用します。

## VCの自動接続と退出

「Discord接続」で接続先VCを設定し、「人が入室したら自動接続」「人がいなくなったら退出」を選びます。「アプリ起動時にBotを接続」はDiscordへのログインの設定で、VCの自動接続とは別です。

Botを除いた人の在室状況をサーバーごとに判定します。起動・設定保存・Discordの復帰時に現状を反映し、入退室・移動時と30秒ごとの確認で追従します。1サーバーの接続失敗は他サーバーの接続や履歴取得を止めません。無人時は接続待ちも取り消し、そのサーバーのDiscord向け読み上げ・メディアの待機を取り消します。他サーバーとマスタ再生は継続します。最後の人の退出通知は無人VCへ読み上げません。手動の接続ボタンでは空のVCにも接続できますが、無人時退出がONなら次の判定で退出します。

検証では実音声の帯域応答・圧縮・低音量のOpus送信、減衰とBGMフェード、Electronでの設定保存と再読み込みを確認します。VC在室・入退室・失敗・接続中の退出は模したDiscordイベントで確認し、Botトークンを使った実サーバー接続は含みません。
