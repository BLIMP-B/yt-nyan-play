# 統合元の全機能を移植するための対応表

更新日: 2026-10-05。ユーザー要件として、**VOICEVOX以外の統合元アプリケーションの全機能を統合対象**とします。VOICEVOXはずんだもんの全声種を使う音声生成を必須とし、本体の全UI・編集機能は移植対象にしません。

## 現時点の確認状況

| 統合元 | 全機能移植 | 回収・確認状況 | 次に必要な材料 |
| --- | --- | --- | --- |
| Discord読み上げBot | 必須 | 利用製品・版・ソース未特定 | 製品URL、利用版、全コマンド・設定、ソースまたは公式仕様 |
| 読み上げちゃん | 必須 | 利用版・設定・ソース未取得 | 配布元、利用版、全設定・辞書・音声連携、公式仕様 |
| DiSpeak | 必須 | 公開リポジトリと説明を確認。全機能の棚卸しは未実施 | 実際の利用版、設定、公開ソースとUI・操作説明の照合 |
| AHKのブラウザ再生処理 | 必須 | 過去チャット末尾のみ取得。再生処理本体は未回収 | 最終版AHK、設定ファイル、呼び出す外部スクリプト、全分岐・ホットキー |
| VOICEVOX／代替経路 | 全声種の音声生成は必須 | 公式のずんだもんトーク8スタイルとAPIを確認 | エンジン・モデル版、全種合成再生試験、配布条件 |

この一覧は全機能を列挙済みという意味ではありません。未取得の仕様を推測して「網羅済み」と扱わず、元の製品・バージョンを確定した上で、下記の形式で一機能ずつ管理します。

## 一機能ごとの記録形式

| 項目 | 記録内容 |
| --- | --- |
| 機能ID | 統合元と機能を識別する固定ID |
| 元の製品・版 | 対象となる配布物、ソースコミット、仕様書の版 |
| 元の機能 | メニュー、設定、コマンド、ホットキー、API、条件分岐と利用者に見える動作 |
| 根拠 | ソース位置、公式説明、再現できる操作例 |
| 入出力・設定 | 引数、保存データ、辞書、声種、エラー時の振る舞い |
| 統合先 | Discord.js Bot、音声生成、再生管理、設定画面のどこに移すか |
| 移行方法 | 設定・履歴・辞書・外部連携の引き継ぎ |
| 検証方法 | 元の操作から統合後まで通して確認できる受け入れ試験 |
| 状態 | 未調査、仕様確認、実装中、検証済み、制約の解決待ち |

同じ機能が複数の統合元にある場合は共通実装にまとめても構いませんが、各統合元の設定と振る舞いの対応は残します。元の機能がVOICEVOX以外の音声エンジンに依存する場合も、その連携機能は移植対象です。依存するエンジンの入手・利用許諾・設定方法を別途整理し、ずんだもんだけで全移植完了とは扱いません。

元の認証方式や外部APIが現在のDiscord.js Botと合わない場合は、代替実装と元の機能との対応を記録します。移植困難な機能を黙って削除せず、未解決として残します。

## 完了の判定

統合元の全メニュー・設定・コマンド・分岐を調べ、機能対応表に漏れがないことを確認します。各行について移行と操作を検証し、未実装・未解決の行がある間は「全機能統合完了」としません。

これに加え、常時稼働Windows PC上のDiscord.js Botとしての接続維持、再起動・復帰、キューの永続化、読み上げとメディア再生、上流Chrome拡張との互換性を検証します。
