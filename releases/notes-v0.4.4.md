にゃんとーく〜Damare〜と、送信側Chrome拡張にゃんぷれいをまとめた検証版です。

| ファイル | 用途 |
| --- | --- |
| `NyanTalk-Damare-Setup-0.4.4-x64.exe` | Windows x64インストーラー |
| `NyanTalk-Damare-0.4.4-x64.zip` | Windows x64展開用パッケージ |
| `yt-nyan-play-0.1.2.zip` | にゃんぷれいChrome拡張。展開後、Chromeの拡張機能画面から読み込み |
| `SHA256SUMS.txt` | 配布ファイルのSHA-256 |

Discord音声の生成タイミングをDiscord側へ合わせ、メディア取り込みを20ms単位にまとめて80msのバッファを設けました。OpusのDTXを無効にし、VC接続中は小音量・無音も連続送信します。音量とダッキングは既存設定を使います。

チャットの `教育(単語=読み方)`、`忘却(単語)`、`無音(単語)` を既定で有効にしました。括弧・等号の全角半角と混在、再教育、教育だけの忘却、再起動後の保持に対応します。

Android導入時に大量の進捗表示で停止する問題と、仮想端末作成に必要なJavaプロパティの不足を修正しました。内部ブラウザにはサービス別のログイン画面を追加し、次回起動・全サーバーの再生でログイン保存領域を共有します。Premium等の広告非表示はサービス側の契約に従います。

LinuxとWindowsで84件の自動試験、実Electronの連続読み上げ・動画音声取り込み・Discord用Opus変換、ログイン画面とCookie保持を確認しました。60msの処理遅延と約−60dBの信号を使った試験も通過しています。Windowsで公式SDK・Google Play API35イメージ導入とAVD作成を確認しました。ニコニコ `sm9` は広告終了後の動画本体の音声を確認しました。

実Botから利用者のDiscord VCへの到達、実VOICEVOXモデル、実アカウント認証・Premium適用は未確認です。指定YouTube `ro_v7LqdI58` はCIでログインが要求され、実音声を確認できていません。AndroidはWindows CIで自動・ソフトウェア描画の両方とも起動完了待ちでタイムアウトし、Google Play内ログインは未確認です。SDK導入成功と端末起動成功を区別します。棒読みちゃん原本とのWindows比較・全機能完全互換、SNS向けChrome検出UI、LANブラウザ通話は未完です。原本・個人辞書・認証設定は同梱していません。
