# にゃんとーく〜Damare〜 v0.5.7 / にゃんぷれい v0.2.2

音声の初期設定を不安定なネットワーク向けに変更しました。Discordへ送る読み上げ・メディア・時報は48 kbpsの固定ビットレートを使い、小さい音と無音も継続して送信します。設定画面から16〜384 kbpsの整数で変更できます。プリセット選択後も個別に調整できます。

VC受信とメディア転送の初期バッファを240 msにし、短い受信欠落を減衰で補います。受信と再購読の繰り返しで発生するOpusのWASMメモリ破損を修正しました。古い受信ストリームのエラーが次の受信を終了する問題も修正しています。

120 msのOpusパケットと多人数のデコーダーの再生成、遅延・欠落・帯域制限を加えた音声試験を追加しました。WindowsのElectronで受信からPC音声までを確認する試験も含みます。実Discord VCでの音声聴取は未確認です。

- Windowsインストーラー: `NyanTalk-Damare-Setup-0.5.7-x64.exe`
- Windows ZIP版: `NyanTalk-Damare-0.5.7-x64.zip`
- Chrome拡張: `yt-nyan-play-0.2.2.zip`
- ファイル検証: `SHA256SUMS.txt`

既存の設定を引き継ぎ、音声の通信環境を「不安定な回線」で追加します。PC音声の待ち時間と音質を優先する場合は通信環境を変更してください。Chrome拡張はv0.2.2です。
