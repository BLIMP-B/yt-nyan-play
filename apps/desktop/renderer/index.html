共通時報

停止中

「にゃんとーくが〇〇時をお知らせします」と4点時報をマスタ再生として共有します。4点目をPCの時計の正時に予約し、通常の読み上げへ最優先で割り込みます。Discordの通信遅延は別に加わります。

PC内の小型言語モデル

公式OllamaとQwen3 0.6Bをアプリから管理導入します。初回は実行環境とモデルのダウンロードが必要です。資料の単語と文章生成はPC内で処理します。既存のOllamaも指定できます。

サーバー別の生成文とBGM

選択したチャンネルの履歴を少量ずつ取得します。取得済みの直近の投稿から文章を生成し、残りの履歴は5分ごとに続きを取得します。資料がまだない場合は共通時報のみ流れます。BGMは生成文の名詞2語で検索し、読み上げ終了から1.5秒後に設定した時間で消して停止します。フェードイン・アウトの初期値は各3秒です。

サーバーとチャンネルIDを入力

PCのスピーカーと通話音声

読み上げ・メディア・時報・通話音声に共通のスピーカーです。Discord接続で設定したVCから1つを選択します。Bot自身の声は含みません。選択したVCに人がいればBotを接続し、無人時は退出の設定に従います。

音声の通信環境

ビットレートの初期値は48 kbpsです。16〜384 kbpsで変更できます。初期設定は音切れを抑えるため、通信量を抑え、通話受信とメディア転送に240ミリ秒の待機を設けます。読み上げ・時報も同じ送信設定を使います。小さい音や無音も継続して送信します。保存すると接続中にも適用します。

メディア再生

通話メディアのイコライザー

Discordへ送る動画・音楽と時報BGMに適用します。PCでの再生、読み上げ、時報の音には適用しません。

帯域ごとに−12〜＋12 dB。音が歪む場合は入力ゲインを下げてください。数値を変更するとカスタム設定になります。

通話メディアのコンプレッサー

大きな音を抑えて音量差を整えます。最初は「軽め」をお試しください。設定は保存後、再生中にも反映されます。

読み上げる内容

テンプレート: $nickname$ / $username$ / $text$ / $server$ / $channel$。移動通知では $channel-prev$ / $channel-next$ を使用できます。

設定バックアップにBotトークンは含まれません。
